# AI ChatBot: EmoSync

## Introduce
This is an AI emotion consultant that use Gemini-Pro and Python as programming language to develop. This AI consultant not only supports text-based conversations but also offers 
voice chat for enhance realibility and engaging user experience. 

### Tools
AI: Gemini-Pro
Programming Language: Python
IDE: Visual Studio Code & Google Colaboratory
Deploy Platform: Streamlit
